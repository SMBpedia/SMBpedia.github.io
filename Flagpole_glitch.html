Flagpole glitch

Flagpole glitch (FPG) is one of the time-saving tricks used in speedruns. By grabbing the flagpole from within the base block, the animation of the flag lowering is skipped, generally saving one framerule. FPG requires precise positioning and usually requires multiple frame perfect inputs. In the any% route, FPG can be preformed up to five times.

FPG was discovered in 2007 by the taser klmz.

Sockfolder setup

The most common setup for FPG was found by the glitch hunter Sockfolder in 2016 with a brute force search. It involves landing on the first pixel of the 6th step of the stairs while only holding right, pressing B the frame you land, and then jumping two frames later. When you reach the base block of the flagpole press L, L, L, L+A so that you jump on the first possible frame.

If Mario has good subspeed, the pole inputs can be more lenient, but a bad subspeed can make FPG impossible.

TASing

Technical explanation

In the flagpole collision subroutine, there is a check for if Mario is below a certain point on the screen. If so, it skips ahead past the code that makes the flag lower.

FlagpoleRoutine:
           ...
           lda Player_Y_Position     ;check player's vertical coordinate
           cmp #$a2                  ;if player down to a certain point,
           bcs GiveFPScr             ;branch to end the level
           lda Enemy_YMF_Dummy,x
           adc #$ff                  ;add movement amount to dummy variable
           sta Enemy_YMF_Dummy,x     ;save dummy variable
           lda Enemy_Y_Position,x    ;get flag's vertical coordinate
           adc #$01                  ;add 1 plus carry to move flag, and
           sta Enemy_Y_Position,x    ;store vertical coordinate
           ...
GiveFPScr:

It is unknown why this check exists, but it is theorized it could be a remnant of removed code or as a type of failsafe.

Full flagpole glitch

If Mario grabs the flagpole a pixel lower than a typical FPG, he gets pushed out of the base block to the left, which skips both the flag lowering and Mario walking to the castle. Although this is around two seconds faster, on the NTSC version of the game it cannot be preformed without either clipping into the floor or bouncing off an enemy. On PAL, however, it can be preformed on every flagpole by doing extremely precise pole inputs.

Bullet bill glitch is a full flagpole glitch that uses a bullet bill to grab the flagpole low enough.
