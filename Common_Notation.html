Common Notation

Position String

(e.g. 1D70-1)

The position string is used to precisely keep track of Mario's position as he is moving. On the practice ROM, it it located to the right of Sx. It consists of 4 hexadecimal digits and a constant 0 digit in the format ABC0-D.

Visualization of where the position string has the same value.

Digits B and C

The B and C digits describe where Mario is horizontally. Assuming Mario is moving at max speed down and right, the pixel and subpixel he will be at once he reaches the bottom of the screen are the B and C digits respectively. This means that B and C stay constant while Mario is falling and moving right.

When on the ground, moving one subpixel will change C by 1, and moving one pixel (16 subpixels) will change B by 1.

Digit A

While moving at max speed, Mario's subpixel alternates between two values. Digit A is used to differentiate which set of subpixels Mario is switching between.

Digit A can range from 0 to 4 and is constant while running to the right. When combined with the 8 pairs C can have while moving, all 40 speed values can be represented. Losing 8 subpixels will decrease A by 1.

Digit D

Digit D is the last 2 bits of Mario's vertical pixel. This is equivalent to his vertical pixel modulo 4, so D can range from 0 to 3.

This is used to represent the vertical offset within a position string, since 4 pixels vertically have the same A, B, and C values.

Flashing

(e.g. D5, C4, F7)

While running on the ground, digit C of the position string alternates or "flashes" between two values. The values are 8 apart in hex since mario moves 2 pixels and 8 subpixels every frame. Looking at which values are flashing can often be a quick way to identify if Mario is positioned correctly.

Room Pace

(e.g. 8-E, 1-D)

The second digit indicates the frame within a framerule that a room is entered. It is the value of the framerule counter on the frame the screen loads. On the practice ROM, this is shown to the right of Rx after the dash (directly to the left of Fx). Since framerules are 21 frames long, the value is shown in base 21, meaning the 21 possible values are 0-9 and A-K. A higher number indicates a faster pace.

The first digit is the world number. This convention is a holdover from an old practice ROM made by Sockfolder that replaced the level number with the room pace.

Room Breakdown

(e.g. B>D>63>C+2)

This sequence explains what pace a runner got in each room of 8-4.

The first two digits are the room pace entering walljump room and turnaround room respectively. The third number is the frame Mario enters the pipe to exit turnaround room.

The final numbers indicate the pace entering last room as well as the number of frames gained or lost before touching the axe.
