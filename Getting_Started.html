Getting Started

Before starting your first speedrun, you should familiarize yourself with the leaderboard rules and make sure you are playing on an allowed platform.

Emulator

Running the game on emulator is the most common way beginners start playing. The following emulators are allowed for the leaderboard:

  • Nestopia
  • NestopiaRTA
  • BizHawk (NesHawk core only)
  • OpenEmu (Nestopia core only)
  • MesenRTA
  • Mesen2RTA

NestopiaRTA and Mesen2RTA are the top two recommended emulators. NestopiaRTA tends to have better performance, especially on lower-end hardware, while Mesen2RTA has more features.

You also require a ROM of the game to play on emulator, which cannot be provided as it is copyrighted material. However, you can verify that you have a valid ROM by comparing the checksum to a list of checksums for known good ROMs. You can find the checksum of your ROM using an online tool.

NestopiaRTA

Download

NestopiaRTA is a fork of Nestopia that adds features for timing and verifying runs.

The default settings work fine, but it can be helpful to enable the rewinder under Options>Timing. Keybinds can be customized under Options>Input.

If you get an error about a missing DLL file, make sure you have the DirectX Runtime installed.

Mesen2RTA

Download

IMPORTANT: The base version of Mesen is not allowed for the leaderboard. The RTA version is required.

Mesen2RTA is a speedrunning friendly fork of Mesen. In addition to features for timing and verifying runs, the fork also adds indicators for disallowed features such as game genie codes and runahead. It is also the most accurate of the allowed emulators (however they are all effectively 100% accurate for SMB1).

Upon first running Mesen2RTA, you will be prompted to select controller keybinds. These can also be customized later under Settings>NES>Input. Other keybinds can be changed under Settings>Preferences>Shortcut Keys.

MacOS and Linux

For MacOS, Mesen2RTA is the recommended emulator. OpenEmu is also an option, but it is recommended against because it runs at a slightly slower framerate.

For Linux, there are native builds of Mesen2RTA and Nestopia. However, the native version of Nestopia is recommended against as it runs at a slower framerate and is missing features. Running the Windows version of Nestopia/NestopiaRTA under wine tends to work better, but it might have performance issues depending on your distro or hardware.

Practice ROM

The most updated practice ROM is the Kaname Training Suite. It is highly recommended for practicing all the levels as it includes a level selector, built-in savestates, and a HUD that displays additional information.

You can easily apply it to your ROM using the Kaname Training Suite Patcher.
